**Authors:** Lin Zhao, Yuan Yuan, Feiping Nie, and Xuelong Li  
**Publication status:** Accepted by IEEE Transactions on Knowledge and Data Engineering (TKDE).

Source code, installation instructions, usage examples, and reproduction instructions will be added as they become ready.

## Overview

Hierarchical Nearest Neighbor Chain Clustering (HNNCC) is a topology-driven framework for data stream clustering. It organizes nearest-neighbor relations across multiple resolutions to support online maintenance, resource-bounded pruning, and macro-cluster extraction.
